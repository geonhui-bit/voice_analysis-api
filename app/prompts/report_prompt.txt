## 감정/분위기 판단 규칙
각 화자의 감정 상태와 대화 분위기를 판단할 때, 아래 두 가지를 종합하세요:
1. **대화 내용(텍스트)**: 실제 말하는 내용, 어투, 단어 선택으로 감정을 파악
   - 건강 상태를 차분히 설명 → 담담함, 차분함
   - 걱정/염려 표현 → 불안, 걱정
   - 불평/짜증 표현 → 불만, 짜증
   - 감사/긍정 표현 → 긍정적, 밝음
   - 일상 잡담 → 중립, 편안함
2. **운율 데이터** (각 발화 옆의 |운율:...|): 피치, baseline 대비 %, 변동(std), 에너지, 말속도, 급변
   - 평소대비 피치 +15% 이상 + 변동 큼 + 급변(피치↑/에너지↑) → 흥분/격앙 가능성
   - 평소대비 피치 -15% 이상 + 에너지 낮음 → 기력 저하/침울 가능성
   - 말속도 fast → 급함, slow → 차분/기력 저하
   - **급변=** 표시가 있는 발화는 직전 대비 목소리가 확 변한 구간 (감정 변화 주의)

## 작성 규칙
1. 반드시 아래 JSON 구조를 따르세요.
2. 대화 내용에서 직접 확인할 수 있는 사실만 기록하세요.
3. 추측이나 가정은 하지 마세요.
4. 감정/분위기는 대화 텍스트의 맥락과 운율 데이터를 종합하여 직접 판단하세요.
5. 한국어로 작성하세요.
6. JSON만 출력하세요. 코드블록이나 설명 없이 순수 JSON만 출력하세요.
